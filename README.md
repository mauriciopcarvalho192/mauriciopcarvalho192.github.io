# Loja d'Efeitos Sonoros

Projeto de desenvolvimento web front-end que simula uma loja de efeitos sonoros, com páginas de produtos e organização de recursos multimídia.

## Sobre o projeto

A **Loja d'Efeitos Sonoros** foi desenvolvida como um projeto acadêmico e prático de desenvolvimento web, com o objetivo de criar uma interface para apresentação e navegação por produtos relacionados a efeitos sonoros.

O projeto inclui páginas de produtos, uma interface de carrinho e recursos de áudio e vídeo, explorando a estruturação de páginas e a organização visual de uma aplicação web.

## Funcionalidades

* Catálogo de efeitos sonoros.
* Páginas individuais de produtos.
* Interface de carrinho.
* Apresentação de recursos de áudio e vídeo.
* Navegação entre páginas da aplicação.

## Tecnologias utilizadas

* HTML5
* CSS3
* CSS Grid e Flexbox
* Media Queries
* Áudio e vídeo para conteúdo multimídia

## Estrutura do projeto

* `index.html` — Página principal da aplicação.
* `carrinho.html` — Interface do carrinho.
* `produto-dragao.html` — Página do produto Dragão.
* `produto-passaro.html` — Página do produto Pássaro.
* `css/` — Arquivos de estilização.
* `audios/` — Arquivos de áudio.
* `img/` — Imagens utilizadas no projeto.
* `gif/` — Arquivos GIF.
* `fontes/` — Recursos de fontes.
